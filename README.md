# 📦 NetFlow Almoxarifado

Sistema web desenvolvido para otimizar o controle de estoque e a distribuição de materiais utilizados no dia a dia de uma confecção têxtil.

O objetivo do projeto é substituir processos manuais, reduzir o uso de papel, aumentar a rastreabilidade das movimentações e tornar a gestão do almoxarifado mais rápida, organizada e eficiente.

Este é um **projeto real**, desenvolvido para atender às necessidades operacionais de uma empresa do setor têxtil, com foco na digitalização de processos internos e na melhoria da produtividade.

---

## ✨ Funcionalidades

* 📋 Solicitação de materiais pelos encarregados
* 📦 Controle de estoque em tempo real
* 📉 Alerta de estoque mínimo
* 🚚 Registro de entrega de materiais
* 📝 Histórico completo de movimentações
* 📊 Dashboard com indicadores operacionais
* 🔍 Pesquisa rápida de materiais
* 👥 Controle de usuários e permissões
* 📄 Exportação de relatórios em PDF e Excel

## 🎯 Objetivo

O NetFlow Almoxarifado foi concebido para oferecer uma solução simples, intuitiva e eficiente para o gerenciamento de materiais em ambientes industriais, permitindo o controle de entradas, saídas, níveis de estoque e rastreabilidade das movimentações de forma organizada e segura.

A interface foi projetada com foco na produtividade, priorizando ações rápidas e uma experiência de uso adequada ao ambiente de uma fábrica.

Além de ser um projeto de portfólio, o NetFlow Almoxarifado representa uma solução aplicada a um cenário real, desenvolvida para atender às demandas de uma empresa e utilizada como base para a modernização de um processo operacional.
