# 📦 Horitech Storage

Sistema web de **gestão de estoque e cadastro de clientes**, desenvolvido para centralizar e organizar o controle de peças, produtos e movimentações de estoque de uma empresa.

O objetivo do projeto é substituir controles manuais por uma aplicação simples e organizada, permitindo visualizar rapidamente **fotos dos produtos, códigos, preços, quantidades disponíveis e demais informações importantes de cada item**.

O **Horitech Storage** também está sendo desenvolvido como um projeto prático para aplicar conceitos de desenvolvimento Full Stack, banco de dados e construção de sistemas voltados para problemas reais.

## 🎯 Objetivo

O **Horitech Storage** foi criado para explorar o desenvolvimento de uma solução de gerenciamento de estoque baseada em um cenário real.

A proposta é permitir que produtos e peças sejam cadastrados com informações como **foto, código, descrição, preço e quantidade disponível**, facilitando a consulta e o controle do estoque.

Além do gerenciamento de produtos, o projeto pretende incorporar um módulo de **cadastro e gerenciamento de clientes**, expandindo gradualmente o sistema conforme novas necessidades forem identificadas.

O projeto também serve como ambiente prático para aprofundar conhecimentos em:

* Desenvolvimento de APIs REST
* React e TypeScript
* Node.js e Express
* PostgreSQL
* Modelagem de banco de dados
* Integração entre Front-end e Back-end
* Organização e arquitetura de aplicações
* Git e GitHub
